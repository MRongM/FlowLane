# App Proxy Implementation Plan

> **For agentic workers:** Execute the tasks below with test-driven development and independent review. The user has authorized implementation in this session; no further design approval is required.

**Goal:** Deliver a buildable native per-application proxy utility and auditable network core integration.

**Architecture:** SwiftUI UI + AppProxyKit + a session-scoped privileged supervisor + pinned sing-box. No persistent root daemon or Network Extension.

**Tech Stack:** Swift 6, Swift Package Manager, macOS 14+, sing-box 1.14.3, Python integration harness, Go attribution diagnostic.

## Global Constraints

- Build and ordinary tests never modify routing, DNS or system proxy settings.
- Default unmatched traffic to direct connections.
- Store proxy passwords in Keychain; runtime secrets are mode 0600 and promptly cleaned.
- Never commit downloaded binaries, generated runtime configs, or real credentials.
- Network activation is explicit; stopping and abnormal exit must clean session-owned state.
- Document unknown process ownership, shared helpers, DNS direct policy and rejected matched UDP.
