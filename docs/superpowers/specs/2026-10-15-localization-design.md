# FlowLane 国际化

用户已确认直接实现，首批覆盖 en、zh-Hans、zh-Hant、ja、ko、fr、de、es、pt-BR、ru、ar。

设置页和 macOS Settings（⌘,）共用一个语言偏好，提供“跟随系统”与上述 11 种语言。偏好写入本应用 UserDefaults，保持代理配置和 Keychain 不变。SwiftUI 文案即时刷新，不重建 AppStore、RuntimeController 或编辑表单；原生系统菜单/对话框公共文案在下次启动采用本应用 AppleLanguages。跟随系统读取全局语言列表，不把应用自己的语言覆盖当作系统语言。切换语言不操作网络。

本地化资源放入 AppProxyKit 的标准 .lproj / .strings，Interface 和 Runtime 两张表，英语为开发语言和缺失翻译回退。格式化使用 {0} 等安全占位符，用户名称、路径、凭据和内核日志不作为本地化键或格式串。所有翻译必须具有相同键和占位符。

应用错误、运行阶段与 helper 状态传输稳定消息键和参数，在界面端按当前语言渲染；保留旧字符串字段与旧状态解码兼容。helper 不读取 UI 的语言偏好，SessionRequest 和特权命令保持原有允许字段。原始 sing-box 日志和系统错误详情保留原文，应用说明标明这一边界。

阿拉伯语镜像 UI 布局；IP、端口、文件路径和日志保持 LTR。代理端口输入不使用分组分隔符。原生弹窗标题/确认按钮按当前选定语言生成，用户输入不翻译。

测试覆盖语言匹配（含地区和中文脚本）、英语回退、设置持久化、系统偏好与手动覆盖隔离、占位符完整性、安全插值、已有错误随语言重新渲染、旧状态协议、RTL 和语言切换不重置运行/配置。构建必须复制资源 bundle；脱离开发路径也可读取 11 种资源。截图核对中文、英文、德文与阿拉伯语的界面与设置。
